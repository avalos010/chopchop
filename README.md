# Chop Chop

Chop Chop is a web application that allows users to upload long videos and automatically generates short, engaging reels using AI. The application is built with Next.js, React, and Tailwind CSS, and utilizes Supabase for storage.

## Features

- User video upload and storage using Supabase
- AI-powered video editing to generate short reels from long videos
- Simple and intuitive interface for users to upload and manage their videos
- Global CSS styles using Tailwind CSS

## Technologies Used

- Next.js for server-side rendering and routing
- React for building the user interface
- Tailwind CSS for styling
- TypeScript for type checking
- Supabase for storage and database management
- AI-powered video editing ( details on AI implementation to be added )

## Getting Started

To get started with the project, run the following command:

```bash
pnpm run dev
```
